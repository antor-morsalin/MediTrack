# MediTrack — Pharmacy Inventory Management System

A desktop inventory management application designed for pharmacy owners operating one or multiple outlets.

## Overview

MediTrack explores how database-backed software can help organize medicine inventory within a pharmacy business. The application combines a Windows desktop interface with a relational database, providing a practical setting for applying object-oriented programming and database design concepts.

Developed for the **Object Oriented Programming II** course at American International University-Bangladesh.

## Core functionality

- Medicine inventory management
- Support for single-outlet and multi-outlet pharmacy operations
- A Windows Forms-based desktop interface
- Persistent data storage in Microsoft SQL Server

## Getting started

1. Prepare a Windows development environment with Visual Studio and Windows Forms support.
2. Install or configure a compatible Microsoft SQL Server instance.
3. Open the application source and configure the database connection according to the implementation.
4. Set up the required database schema using the project's database assets, if provided.
5. Build and run the desktop application against a test database.

Do not commit real database credentials or use production pharmacy data for testing.

## Project scope

MediTrack is an academic software engineering project focused on inventory workflows and relational data management, rather than a certified commercial pharmacy management product.
